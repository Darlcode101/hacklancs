# Instagram grid infographic

Three 1080x1350 (4:5) posts that join up into one image across the top row of the @hacklancs profile.

Post them in this order, back to back, so nothing lands between them:

1. `hacklancs-grid-1-post-first-right.png` (ends up on the right: how to sign up)
2. `hacklancs-grid-2-post-second-middle.png` (middle: the key facts)
3. `hacklancs-grid-3-post-third-left.png` (ends up on the left: logo, tagline and date)

`hacklancs-grid-full-3240x1350.png` is the whole design in one image, and `hacklancs-grid-preview.png` shows how it looks on the profile in both the 4:5 and 3:4 grid crops.

These files aren't linked from any page on the site.
